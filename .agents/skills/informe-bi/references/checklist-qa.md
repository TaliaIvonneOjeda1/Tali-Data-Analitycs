# Checklist QA — informe PDF

Marcar antes de dar el informe por cerrado.

## Contenido

- [ ] Responde una pregunta de negocio explícita
- [ ] Audiencia / período visibles en portada o sección 1
- [ ] Resumen ejecutivo sin inventar cifras
- [ ] KPIs con contexto (vs período, filtro o definición)
- [ ] Hallazgos separados de recomendaciones
- [ ] Conclusiones + próximos pasos presentes
- [ ] Limitaciones / supuestos honestos (incl. datos faltantes)

## Visual y marca

- [ ] Logo TaliAnalytics en portada/header
- [ ] Paleta navy/azul de producto
- [ ] Footer con confidencialidad y número de página
- [ ] Gráfico con título específico (o justificación de “sin gráfico”)
- [ ] Barras con eje en 0 / líneas solo si hay tiempo

## Trazabilidad y archivo

- [ ] Anexo con SQL o cuentas que respaldan indicadores
- [ ] Nombre `InformeYYYYMMDD-Consultas.pdf` o `InformeYYYYMMDD-ejecutivo.pdf`
- [ ] Sin PII innecesaria (clientes individuales)
- [ ] Cifras del cuerpo coherentes con consultas del anexo
